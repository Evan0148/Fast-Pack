legacy-icons.png is the original Minecraft Java Edition 1.20.1 GUI icon atlas, used only when a converted legacy resource pack supplies no icon atlas. Existing pack atlases take precedence. The converter replaces only the crosshair region and preserves the remaining HUD graphics.
