# Privacy Policy for Fast-Pack
This privacy statement applies to the Fast-Pack open-source Windows application.

Fast-Pack does NOT collect, transmit, store or share any personal identifiable information, usage data, logs or user statistics from end users.
The software runs fully locally on the user's computer. No user data will be uploaded to any remote server automatically.

Users may choose to manually input network connection parameters; these settings are saved locally on the user's device only and will never be sent outside the local machine without explicit manual user action.

For privacy-related inquiries, please create an issue in this GitHub repository.

This policy may be updated in future releases. All changes will be recorded in the git commit history of this repository.
